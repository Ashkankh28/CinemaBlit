# 🇬🇧 English

## 📖 Overview

CinemaBelit is a web application that simulates an online cinema ticket booking platform.

Users can browse available movies, view movie details, select seats, purchase tickets, manage their profile, and review previous orders.

The project also includes an administration panel for managing movies and users.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/CinemaBelit.git
```

Move the project to your local web server directory (XAMPP, WAMP, or Laragon).

Create a MySQL database.

Import the provided SQL database.

Configure the database connection.

Start Apache and MySQL.

Open the project in your browser.
